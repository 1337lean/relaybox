# Contributing

Issues and focused pull requests are welcome. Before submitting, run `gofmt -w .`, `go vet ./...`, `go test ./...`, `go test -race ./...`, and `go run honnef.co/go/tools/cmd/staticcheck@v0.7.0 ./...`. Changes to forwarding or storage must preserve the atomic acknowledgement invariant, lease ownership, recovery, and retention behavior. Add failure-injection or runtime tests as appropriate, keep the runtime dependency-free, preserve backward recovery of the append-only format, and update operational or security documentation. By contributing, you agree that your work is licensed under MIT.
