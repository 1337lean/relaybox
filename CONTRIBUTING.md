# Contributing

Issues and focused pull requests are welcome. Before submitting, run `gofmt -w .`, `go vet ./...`, `go test -race ./...`, `go run honnef.co/go/tools/cmd/staticcheck@v0.7.0 ./...`, `go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...`, `go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12`, and `go run github.com/goreleaser/goreleaser/v2@v2.17.1 check`. Changes to forwarding or storage must preserve the atomic acknowledgement invariant, lease ownership, recovery, retention, monotonic compaction sequences, and compatibility with existing append logs. Add failure-injection or runtime tests as appropriate, keep the runtime dependency-free, preserve backward recovery of the append-only format, and update operational or security documentation. Release changes must keep the exact six-target validation and pre-publication gates described in [docs/releasing.md](docs/releasing.md). By contributing, you agree that your work is licensed under MIT.
